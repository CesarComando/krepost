# Крепость сквозь время · Dinaburga 1810

Приложение для телефона о Даугавпилсской крепости: старые фотографии, карта точек съёмки, аудиогид, квесты и «паспорт» посещённых мест. Для туристов и семей.

**Открыть:** https://cesarcomando.github.io/krepost/

Автор и владелец проекта — Дайнис Миглан (Daugavpils). Приложение создаётся вместе с Claude.

## Что умеет

- **Старые фото.** Лента снимков крепости с годом, подписью и источником.
- **«Тогда и сейчас».** Камера показывает старый снимок поверх вида в объективе — можно снять то же место сегодня. Снимки остаются в телефоне, в «Библиотеке».
- **Карта.** Точки, откуда сделаны снимки; кнопка «Я здесь»; слой аэросъёмки 1944 года.
- **Аудиогид.** Кольцевой маршрут из 13 точек со вступлением и финалом. Звук включается только по нажатию.
- **Квесты и паспорт.** Отметки «Посещено» и печати за пройденные места.
- **История.** Короткие справки по объектам крепости и раздел «Легенды и правда».
- **Без интернета.** После первого захода приложение открывается и без сети; фото для прогулки можно скачать заранее.
- **Языки:** латышский, русский, английский, литовский, польский, немецкий.

## Как устроено

Это обычный сайт без сборки: файлы лежат как есть и открываются в браузере.

| Файл или папка | Что в нём |
|---|---|
| `index.html` | Всё приложение: внешний вид, экраны и программа |
| `spots.js` | Список снимков: номер, файл, название, год, подпись, источник, группа, точка на карте |
| `guide.js` | Аудиогид: точки маршрута и тексты на трёх языках |
| `quests.js` | Квесты |
| `history.js` | История объектов и легенды |
| `i18n.js` | Механика переводов; исходный язык текстов — русский |
| `i18n-lv.js`, `i18n-en.js` и другие | Переводы. Файлы `et`, `fr`, `it`, `es`, `zh` лежат, но в приложении пока не подключены |
| `sw.js` | Работа без интернета и обновление приложения на телефонах |
| `manifest.webmanifest`, `icons/` | Название и значок для установки на экран телефона |
| `photos/`, `photos/thumbs/` | Снимки и их уменьшенные копии |
| `audio/` | Записи аудиогида |
| `vendor/leaflet/` | Библиотека карты |
| `vendor/fonts/` | Шрифты (лежат на самом сайте) |
| `COORDINATION.md` | Журнал работы: кто за что отвечает, что сделано, что осталось до выпуска |

## Как посмотреть у себя на компьютере

Нужен только Python.

```
python3 -m http.server 8000
```

Потом открыть в браузере `http://localhost:8000/`. При таком запуске статистика не отправляется.

## Как изменения попадают на сайт

1. Правка отправляется в ветку `main`.
2. Через одну-две минуты GitHub сам обновляет сайт.

Что важно помнить:

- **Всё, что лежит в этом хранилище, видно всем** — и на GitHub, и по прямой ссылке на сайте. Пароли, ключи и личные данные сюда не кладутся.
- **При каждой правке приложения номер в `sw.js` (`krepost-vNN`) увеличивается на 1.** По нему телефоны понимают, что вышла новая версия.
- **Перед правкой — прочитать `COORDINATION.md`, после — дописать строку в журнал.** Над проектом работают два чата Claude одновременно.
- **Каждая правка проверяется на экране размера телефона** до публикации.

## Правила проекта

Фотографии:

- не публикуются люди в советской военной форме, в нацистской форме и со свастикой;
- снимки с воздуха и те, что нельзя переснять, идут в раздел «Из архива», а не в ленту;
- чужие раскраски и фото с водяными знаками не берутся;
- у каждого снимка указан источник.

Карта:

- точки не ставятся на проезжей части;
- место снимка привязывают только модераторы. Посетитель может предложить более точное место кнопкой «Точка стоит не там?».

Тексты:

- факт проверяется по источнику; легенда всегда названа легендой;
- слова без рода: «Посещено», а не «был».

## Данные посетителей

- **Местоположение телефона никуда не отправляется.** Оно используется только в самом телефоне: «Я здесь» и «рядом с вами».
- **Снимки посетителя хранятся только в его телефоне.**
- **Статистика анонимная:** язык, какие разделы и фото открывались, какие места сняты. Без имён и без номера телефона или устройства.
- **Рассказ или отзыв** уходит модератору, только если посетитель сам нажал «Отправить». Контакт автора рассказа видит только модератор.
- **«Точка стоит не там?»** отправляет место метки на карте, а не место телефона.
- Карта загружается с серверов OpenStreetMap, статистика хранится в Supabase, сайт лежит на GitHub. Шрифты и библиотека карты лежат на самом сайте.

Полный текст для посетителей — в приложении: «Настройки» → «О приложении».

## Модераторы

Модератор видит статистику, проверяет рассказы и предложенные точки, скрывает снимки и привязывает их к карте. Вход — по ссылке с `?admin` в конце, логин и пароль выдаёт Дайнис. Паролей в этом хранилище нет.
